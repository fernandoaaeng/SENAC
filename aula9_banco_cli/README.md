# Aula 9 — Passos de Orientacao a Objetos

Mini demonstracoes em Python, uma por arquivo. Nao precisa instalar nada alem do Python 3.

## Como rodar

No terminal, entre nesta pasta:

```bash
cd aula9_banco_cli
```

Depois execute **um passo de cada vez**:

```bash
python passo1_classe_objeto.py
python passo2_encapsulamento.py
python passo3_heranca.py
python passo4_polimorfismo.py
```

O passo 5 separa as classes em um pacote `models/`. Rode a partir da subpasta:

```bash
cd passo5_modulos_pacotes
python main.py
```

Cada script imprime a demonstracao no proprio terminal (nao abre navegador).

## O que vem depois

- CLI completo **sem** classes: pasta `banco_cli_completo_estruturado`
- CLI completo **com** classes: pasta `banco_cli_completo_orientado`
