# Mini banco CLI — programacao estruturada

Mesmo banco da versao orientada a objetos, mas **sem classes**: clientes e contas sao dicionarios, e poupanca/corrente viram `if`/`else` nas funcoes.

Compare com `banco_cli_completo_orientado`.

## Como rodar

No terminal:

```bash
cd banco_cli_completo_estruturado
python main.py
```

O menu aparece no terminal. Digite o numero da opcao e pressione Enter.

Dados ja prontos para a aula:

- Ana, CPF `1`, conta poupanca `1001`, saldo 1000
- Bruno, CPF `2`, conta corrente `1002`, saldo 100 (limite 200)

Para sair: opcao `0`.

Nao precisa instalar bibliotecas extras — so Python 3.
